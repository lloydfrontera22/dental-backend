DentaCare
 

API

Connect this clinic's data to your n8n pipeline (WhatsApp booking, etc).

1. Base URL

Point every n8n HTTP Request node at this address, plus the endpoint path from the table below.

2. API key

Send this on every request as the header x-api-key. n8n never needs your login password — this key is what identifies your clinic instead.

Regenerating creates a brand-new key automatically and invalidates the old one immediately — update it in n8n's HTTP Request nodes right after, or that workflow will start failing.

3. Endpoints n8n can call

GET
/api/slots/available?date=YYYY-MM-DD

Returns this clinic's open slots for that date. Use it to show the patient their options on WhatsApp.

POST
/api/bookings

Books a slot. Body: date, startTime, endTime, patientName, patientPhone. Saved bookings show up live on the Dashboard, tagged as source "whatsapp".

4. In n8n

In the HTTP Request tool node your AI Agent calls, set the URL to the base URL plus the endpoint path above, and add a header named x-api-key with the value from step 2.
